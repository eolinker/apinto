# 模型资源定价
## 计费模版
- 模型定价在供应商详情中，模型的定价模式由供应商决定。例如openai和deepseek会是两种完全不同的定价模版
- 自定义渠道定价时，可选定价模版。例如来自于gptpro的openai和来自于官方的openai都使用的是同一套定价模版
- 主流模型的计费模板由eolink预置写入到代码中，暂时不支持系统管理员修改主流模型的定价模版。

- 计费模版定义，以下是openai供应商的定价模版的表头示例
  - 模型定价支持三种标准模式
    - token计费：会分为input和output两个价格，如果两个价格同价就写一样的数字即可，显示还是两个价格显示。
    - 按次计费：生歌模型等会按单次调用计费（例如谷歌的Lyria 3）
    - 按秒计费：视频模型都会按秒计费
  - 高级计费模式
    - 基本上主流的新模型都会有不同的精细计费逻辑，通过模型返回信息中的某些变量可以分层收费。这些计费逻辑可以基于一定的框架做成计费脚本。
    - 视频模型必定是使用高级计费脚本来实现不同的帧率每秒不一样的计价

模型定价
在供应商详情中，有模型定价菜单。模型定价菜单下有三个tab，分别是售价、官方价、进货价
官方价
- 标价tab下的数据，由定价模版预置填入，为该供应商模型的官方价格。
- 在表格右上角会显示为“该价格为官方供应商价格”
- 该表格在渠道管理页面中不可编辑，是作为其中一个基准价展示的。当前该价格仅可后台调整计费模版文件编辑（后续迭代会开放系统后台可管理）
- 标价是对应模型前台商品详情页中的划线价。
[图片]
进货价
- 进货价tab下的数据，由上游渠道提供的进货价决定。
- 表格右上角显示当前渠道的上游渠道，如果本身是系统的默认租户“Apipark”，那么这个进货价中所有数据置空。
- 进货价的价格不可编辑
[图片]
售价
- 售价是实际售卖价格，是该模型在列表和详情中显示的核心价格
- 表格中所有数字均可单独编辑，在单元格中编辑的数字，右侧有重置按钮，点击后价格重置为官方价
  - Advanced Billing中的价格也可单独编辑，但编辑时无重置按钮。
- 完成编辑后，点击右上角的保存定价按钮后，才实际修改价格。点击保存定价按钮时，系统会检查售价是否低于进货价，低于进货价的会弹窗提示并自动替换成进货价。
[图片]
- 售价右上角有开启动态调价的按钮，开启后出现动态调价操作按钮
[图片]
动态调价策略
- 点击管理动态调价策略按钮，弹窗显示动态调价策略清单
[图片]
- 弹窗底部直接选择需要新增的策略，策略字段包括
  - 策略名称：策略名称，用于区分不同策略的意义。
  - 应用模型：当前供应商下的模型名称，仅可选择未被其他策略选中的模型。已被其他策略命中的模型名称在这个可选列表中不显示。
  - 参考价格：参考价格可选官方价或进货价作为标准，然后增加折扣比例。
    - 进货价作为标准时，折扣需要大于100%
    - 官方价作为标准时，折扣需要小于100%。并且如果这个折扣最终计算后，实际金额少于进货价，则系统会自动切换为进货价。（即目前系统不支持亏本操作，后续亏本操作支持时通过扣渠道本金实现）
- 新建策略时，可选择该策略为“兜底策略”。勾选新建策略窗口右上角的“设为兜底策略”选项即可
  - 勾选为兜底策略后，策略名称会自动填入兜底策略文字，并支持继续修改。
  - 勾选为兜底策略后，不需要选择应用模型选项。因为该策略是为未被其他策略命中的模型设置的。
  - 兜底策略未非必须创建的策略，即渠道管理员可以仅对部分模型创建动态策略，其他模型手动修改价格，不执行兜底。
  - 兜底策略创建后，后续新建弹窗右上角就没有“设置为兜底策略”选项，除非把原来的兜底策略删除。
  - 开启兜底策略的好处之一是，上游新建了模型后，如果这个新模型当前渠道未定义价格策略，那么也能跟随兜底策略生效动态价格。
[图片]
- 命中了策略后，该模型在售价列表中不可手动编辑。当右上角关闭动态调价后，那么售价中之前被动态价格调整的价格，恢复为默认价（官方价）。注意：未受动态调价影响的模型价格无论是否开启调价，都不应受影响，即原来手工编辑了什么价格，就什么价格。不要因为关闭动态调价而影响其价格。
